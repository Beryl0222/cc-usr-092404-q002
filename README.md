# 野生菌样本联检

急诊、疾控和实验室围绕一次误食事件交接样本、分送形态学/毒素/分子检测，
并在检测结果晚到时修订联检结论。系统保证：**入口证据不含糊、样本数量
守恒、交接幂等、已签发结论不可变、服务中断可安全续跑。**

## 分层

| 模块 | 职责 |
| --- | --- |
| `ingress.py` | 严格证据入口。字节级 JSON 解析（拒绝重复键、尾随内容、编码错误）+ 声明式字段模式（拒绝未知字段、缺失、类型错误、非法时间）。拒绝时生成 `QuarantineRecord`，保留原始字节 SHA-256、字节片段（base64）与每个问题的行/列/字符偏移/字节偏移/JSON 指针。 |
| `contracts.py` | 最小交接信封合同 `DomainRecord` 与 `load_record`；旧调用方遇到歧义文件会收到携带隔离记录的 `EvidenceRejected`。 |
| `commands.py` | 业务命令合同：`intake / split / consume / supplement / record_result / create_conclusion / revise_conclusion / issue_conclusion`，复用入口同一套语法与定位机制。 |
| `messages.py` | 命令字节规范构造器（稳定键序的 UTF-8 JSON）。 |
| `ledger.py` | 保管链台账：事件溯源式只追加事件流、分样树、耗用、补样、结果、结论版本/更正/回执、危急通知去重；快照原子落盘。 |
| `runner.py` | 可恢复联检执行器：把命令字节归档到作业目录，中断后从头重放同一批字节。 |

`fixtures/sample_transfer.json` 仍是一份通过严格入口的脱敏信封样例。
新增状态与字段必须先在合同层声明，并说明迁移方式（`schema_version`）。

## 关键规则

- **重复键不再“取后值”**：同一对象两次 `record_id`（或任意键）在形成领域
  记录前被拒绝，定位到后一次出现的行列，并在问题描述中给出首次出现位置。
- **尾随内容/混合文件拒绝**：一个文档只允许一个顶层 JSON 值。
- **父子数量守恒**：`split` 强制 `子样合计 + 父样剩余 == 父样现有量`；
  `ChainLedger.mass_balance(root)` 对整棵分样树核查
  `初始量 == 各节点剩余 + 全部耗用`，失衡命令整体拒绝、不留半成品。
- **耗用一次性**：同一样本同一联检项目只能耗用一次，复测必须先补样；
  子样可在拆分时声明 `tests` 收窄（必须为父样项目子集）。
- **幂等**：以原始字节 SHA-256 为登记身份。原样重送返回首次登记事件序号，
  不重复登记；同一坏文件重送复用首次隔离记录。
- **暂停关联**：文件名相同但内容不同、或消息编号曾对应不同字节时，登记被
  挂起为 `HoldRecord`（持久化），等待人工裁决，绝不自动顶替。
- **晚到结果路由**：结果只更新同事件内依赖该检测项目且**未签发**的结论
  （生成可审计的新版本）；已签发版本不可变，只追加 `Correction` 与接收
  回执事件（回执引用来源消息、字节摘要和签发版本号）。直接修订已签发结论
  被拒绝。
- **危急通知不重发**：通知带稳定去重键（`样本:项目:结果版本`）并绑定结果
  事件序号；台账先落盘再外发，续跑/重放不二次耗用样本、不二次通知。

## 测试与构建

执行测试（四份测试分别对应混合文件、重复键、分样守恒与恢复）：

```bash
python3 -m unittest discover -s tests
```

- `tests/test_ingress.py` — 重复键、尾随内容、未知字段、非法时间、混合文件、字节摘要与定位
- `tests/test_chain.py` — 交接/拆分/耗用/补样/结论修订的父子数量守恒与保管链
- `tests/test_handoff.py` — 原样重送幂等、同名异内容暂停、晚到结果路由、签发后更正回执
- `tests/test_recovery.py` — 中断注入后续跑不重复耗用/不重复通知，以及最终状态呈现

执行编译检查：

```bash
python3 -m compileall -q src tests
```
